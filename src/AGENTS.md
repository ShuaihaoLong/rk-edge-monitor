# src 目录约定

项目使用 C++17，新增和修改代码须保持 C++17 兼容。线程使用 `std::thread`、显式停止和 `join`，不使用 `std::jthread`、`std::stop_token` 等较新标准接口；新标准特性留待后续专门升级时考虑。

仅存放正式运行所需的应用组装和模块实现。测试、模拟服务、演示流程放在 `tests/` 或 `examples/`，不要为了验证而让正常启动的应用立即退出。保持框架必要且清晰，暂未实现的业务不添加模拟功能。

正式代码不保留演示示例、测试说明、占位教学或历史修改说明类注释；保留必要的接口契约、资源所有权、并发及异常处理原因。
