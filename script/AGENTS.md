# script 目录规范

用户要求：以后本目录新增或修改的脚本，都必须在文件开头（shebang 之后）提供中文使用说明，包括用途、调用示例、参数/环境变量、运行前提、输出位置及重要副作用。

- 关键步骤补充中文注释，解释设计原因和边界条件。
- 支持 `--help`；脚本可从任意工作目录调用，以自身路径定位项目根目录。
- 不在脚本中保存密码。构建使用 CMake + Unix Makefiles / GNU Make。
- 更改后验证语法与相关行为；同步类脚本优先使用试运行或本地模拟验证。

- PC 部署/更新统一入口为 `deploy.sh`，复用 `build.sh`、`package-monitor.sh` 和板端 `install-monitor.sh`。后续程序产物、配置、静态资源、安装路径或服务依赖变化时，同步维护这条部署链路及 README 使用说明；验证预览和失败退出，不另建重复部署流程。
