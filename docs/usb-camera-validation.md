# USB 相机验证记录

> 阶段验证记录（2026-09-07）。其中关于下游解码尚未实现的结论只适用于本轮测试；当前模块说明见 [Camera](modules/camera.md) 和 [Media](modules/media.md)。

2026-09-07，通过 SSH 在 RK3588（Linux 5.10.209，aarch64）验证。相机为 SYD USB Camera（0bda:d576），uvcvideo，USB 480 Mbps。使用 `tests/camera_probe.cpp`，帧数据仅在内存中检查，不保存图像。

| 测试 | 结果 |
| --- | --- |
| 主机 CTest | 6/6 通过，包含队列、邮箱、服务、日志、应用和相机服务 |
| ARM64 交叉编译 | 成功 |
| 板端相机服务测试 | 通过 |
| MJPEG 1920×1080，10 秒 | 296 帧，29.5149 FPS，应用队列丢帧 0，超时 0 |
| MJPEG，消费者每帧延迟 100 ms，10 秒 | 采集 297 帧、消费 100 帧，29.4784 FPS，应用队列丢帧 193，超时 0 |
| YUYV 640×480，5 秒 | 148 帧，29.4068 FPS，应用队列丢帧 0，超时 0 |
| MJPEG 1920×1080，60 秒 | 1775 帧，29.577 FPS，应用队列丢帧 0，超时 0 |
| 主程序 SIGINT / SIGTERM | 退出码 0，停止后可再次启动采集 |
| 元数据节点 `/dev/video22` | 拒绝启动，退出码 1 |
| 不存在的设备节点 | 报告打开失败，退出码 1 |

MJPEG 检查 JPEG SOI 标记；YUYV 检查帧长度覆盖 stride × height。没有执行完整图像解码或视觉质量检查。应用队列丢帧计数不代表驱动丢帧计数；FPS 包含启动等待。

假视频源测试覆盖慢消费者丢帧、帧数据独立生命周期、阻塞读取停止、重复停止、重启后新队列、连续超时、读取错误和打开失败。

尚未执行 10 分钟以上持续采集、真实物理拔插或图像解码验证；自动重连、MJPEG 解码和下游业务不在本轮实现中。
